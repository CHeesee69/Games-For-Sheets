# Games For Sheets!
A few classic games recreated on Google Sheets! I might add more games, but the ones currently on there are Snake, Blackjack, Minesweeper, and Sudoku. I am trying to get Tetris to work, but it's not cooperating, and it might be a while until it does.
 
<img width="1852" height="816" alt="image" src="https://github.com/user-attachments/assets/c073ab6f-de96-4605-aa92-ce9d3228313f" />
 
## Features
- Google Sheets recreations of Minesweeper, Snake, Blackjack, and Sudoku.
- Made with Google Apps Script (basically JavaScript for Google apps)


## Requirements
- A good, stable internet connection
- A powerful enough device to load Google Sheets
- A browser

## Use

If you want to try it out for yourself, just go to [this sheet](https://docs.google.com/spreadsheets/d/14v2c1DsDYz6Efg_-XwYdSOKMCCL0Xanr9LB-ZKnGtPw/edit?gid=0#gid=0), and make a copy of it by going to __File -> Make a Copy -> Make a Copy__. Then you can select the game you want to play from the bottom and press Start. How to play the different games is realy game specific, so there's a little snippet of text to help you get on the right track to start playing it.
