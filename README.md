# Snake-for-Sheets
Simple 15x15 snake game for Google Sheets! Yay! It's made with the Google Apps Script extension, which allows JavaScript code to read and edit the spreadsheet.

## Features
- 15x15 game of snake
- Leaderboard
- (Almost) Instant controls

## How to use
To try Snake for Sheets, go to [this link](https://docs.google.com/spreadsheets/d/14v2c1DsDYz6Efg_-XwYdSOKMCCL0Xanr9LB-ZKnGtPw/edit?usp=sharing) and make a copy. Press the start button and use the checkboxes to turn your snake left or right. Then play to your heart's content!
